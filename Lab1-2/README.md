# Labs 1 and 2: Client and Server Setup

Establish the client and server environment used by the later network-security labs.

## How It Works

The setup material includes public SSH keys and account notes associated with the course machines. The later exercises rely on this client/server arrangement for controlled traffic generation, packet inspection, and host configuration.

## Main Tasks

- Prepare the course client and server machines.
- Use public keys for the required SSH access setup.
- Check connectivity before working through the later lab exercises.
