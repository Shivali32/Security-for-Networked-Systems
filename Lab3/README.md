# Lab 3: Encryption and Cipher Modes

Compare symmetric cipher modes, image encryption, ciphertext modification, and public-key encryption artifacts.

## How It Works

Plaintext messages and a bitmap provide inputs for the encryption experiments. The files record ECB, CBC, and OFB comparisons, decrypted outputs after modifications, and an RSA-encrypted symmetric key. The write-up explains visible image patterns and error propagation rather than treating encryption alone as integrity protection.

## Main Tasks

- Compare encrypted bitmaps under ECB and CBC.
- Observe how changed ciphertext affects decrypted message blocks.
- Inspect the key-encryption artifacts and the written explanation.
