# Lab 6: Password Auditing

Study password-hash auditing with John the Ripper in the course lab environment.

## How It Works

The report describes dictionary-based candidate generation and transformation rules applied to supplied lab hashes. The discussion relates the observed results to password complexity, hashing, salting, and the value of authorized password audits.

## Main Tasks

- Compare dictionary candidates and rule-based transformations.
- Record the commands and outcomes in the lab report.
- Explain why weak password choices remain vulnerable despite hashing.
