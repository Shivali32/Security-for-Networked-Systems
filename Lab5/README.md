# Lab 5: Certificates and Trust

Examine certificate validation, trust chains, revocation, and browser identity checks.

## How It Works

The written questions compare certificate-authority verification methods, extended validation, root-certificate trust, OCSP and certificate-revocation lists. They also discuss certificate expiration and the fields used to associate a certificate with a website.

## Main Tasks

- Explain certificate issuance and identity verification.
- Compare revocation mechanisms and certificate lifetimes.
- Describe how a browser checks a certificate chain and hostname.
