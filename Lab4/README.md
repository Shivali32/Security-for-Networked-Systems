# Lab 4: OpenPGP Email

Document OpenPGP key generation, fingerprint verification, message signing, and email encryption.

## How It Works

The report follows a Kleopatra and Outlook workflow: generate a protected key pair, inspect the recipient key fingerprint, import the public key, and prepare signed or encrypted messages. The exported public key accompanies the report for identification and verification.

## Main Tasks

- Generate and identify an OpenPGP key pair.
- Verify and import the recipient public key.
- Compare signed, encrypted, and signed-and-encrypted messages.
