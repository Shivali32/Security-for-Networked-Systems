# Lab 7: Rootkit Traffic and Detection

Inspect packet captures and host evidence from the course rootkit-analysis exercise.

## How It Works

The lab report compares TCP, UDP, and ICMP-related evidence and discusses host integrity checks and rootkit detection. Captures and screenshots accompany the written observations so that traffic properties can be inspected alongside the report.

## Main Tasks

- Inspect the supplied captures in a packet-analysis tool.
- Compare transport behavior across the recorded exchanges.
- Review the host-detection observations and supporting screenshots.
