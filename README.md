# Security for Networked Systems

This repository contains coursework on host and network security, beginning with the client and server setup used by the labs. The exercises examine symmetric encryption modes, OpenPGP messages, certificate trust, password auditing, rootkit-related traffic, firewall policies, and intrusion-detection rules. The material combines written explanations with command files, encryption outputs, screenshots, packet captures, and Snort alerts. OpenSSL-related artifacts illustrate confidentiality and error propagation, while the later labs compare evidence from packet inspection and host checks. The firewall and detection material uses iptables and Snort to express and inspect network policy in the course environment.

## Assignments and Labs

- **[Labs 1 and 2: Client and Server Setup](Lab1-2/)**  
  Establish the client and server environment used by the later network-security labs.

- **[Lab 3: Encryption and Cipher Modes](Lab3/)**  
  Compare symmetric cipher modes, image encryption, ciphertext modification, and public-key encryption artifacts.

- **[Lab 4: OpenPGP Email](Lab4/)**  
  Document OpenPGP key generation, fingerprint verification, message signing, and email encryption.

- **[Lab 5: Certificates and Trust](Lab5/)**  
  Examine certificate validation, trust chains, revocation, and browser identity checks.

- **[Lab 6: Password Auditing](Lab6/)**  
  Study password-hash auditing with John the Ripper in the course lab environment.

- **[Lab 7: Rootkit Traffic and Detection](Lab7/)**  
  Inspect packet captures and host evidence from the course rootkit-analysis exercise.

- **[Lab 8: Firewalls and Intrusion Detection](Lab8/)**  
  Work with iptables filtering and Snort rules for traffic monitoring in the lab network.
